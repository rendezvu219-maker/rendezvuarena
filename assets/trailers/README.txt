Place each hero's local trailer video and still image in this folder using the same four-digit hero ID:

  assets/trailers/0001.mp4
  assets/trailers/0001.png
  assets/trailers/0002.mp4
  assets/trailers/0002.png
  ...
  assets/trailers/0039.mp4
  assets/trailers/0039.png
  assets/trailers/0040.mp4
  assets/trailers/0040.webp

Video fallback extensions: .mp4, .webm, .mov.
Still-image fallback extensions: .png, .webp, .jpg, .jpeg.

Videos play once only. When a video finishes, the matching still image remains on screen until the next hero is picked or banned. If the still image is missing, the normal full-body hero art is used.
