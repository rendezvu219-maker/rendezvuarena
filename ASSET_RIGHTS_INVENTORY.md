Updated: 1 August 2026

This inventory separates original project material from third-party game content. It is a release checklist, not a licence opinion.

| Location | Contents | Current treatment | Public-release action |
|---|---|---|---|
| `server/`, `js/`, `css/`, root HTML | Original application code and UI | Included under `LICENSE.md` | May be published by the project owner, subject to third-party dependencies and any contributed code rights |
| `assets/heroes/` | 410 character/skill/reference image files | Third-party game artwork; excluded from code licence | Obtain written permission or replace/remove before a public repository or public deployment |
| `assets/divine-cards/` | 37 card image files | Third-party game artwork; excluded from code licence | Obtain written permission or replace/remove before public distribution |

| User uploads at runtime | Tournament evidence and attachments | Not included in this package | Configure retention, access controls and deletion procedures before launch |
