# Security Policy

Report security issues privately to the email configured as `PUBLIC_CONTACT_EMAIL` for the production operator.

Do not post credentials, session cookies, room links, OAuth tokens, private tournament notes, evidence or personal information in a public issue.

Before reporting, include the affected version, route or component, reproduction steps, impact and any non-sensitive logs. The operator should acknowledge reports promptly and rotate any credential that may have been exposed.

Supported release: `1.0.x`.
